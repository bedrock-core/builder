Welcome to your addon's in-game guide. Pages are MDX files under
`guides/<locale>/` — the guides builder stage compiles them into a manifest
that `core.register()` publishes, and the shared config UI renders for every
player. Each line of prose becomes a localized `.lang` entry automatically:
add a `es_ES/` folder with the same file names to translate the whole guide.

- Edit this page in `packs/BP/guides/en_US/intro.mdx`
- Group pages in folders with a `_category_.json`
- Link between pages with relative links

See [First Steps](./getting-started/first-steps.mdx) to begin.
