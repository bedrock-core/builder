Scaffold full, plain script and resource-only projects with `core-builder` commands,
named packs and build, watch and GameTest profiles. Define display metadata and
stable creator/pack identity once in configuration, inherit manifest defaults and
import generated project metadata for runtime registration. Full starters keep
translations in the owning behavior pack and link resource output through native
dependencies. Pin the UI toolkit and its render-pack dependency together, including
the modules resource-pack description in both behavior manifests.
